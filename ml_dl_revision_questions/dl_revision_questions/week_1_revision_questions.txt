## Exercise 9: "The Vanishing Gradient Problem"

| Question | Your Answer |
|----------|-------------|
| 1. What is the vanishing gradient problem? | |
| 2. Which activation functions suffer from it? | |
| 3. Which activation functions do NOT suffer from it? | |
| 4. Why does it prevent deep networks from learning? | |
| 5. Name two mitigation strategies. | |

<details>
<summary>📖 Click for Answers</summary>

| Question | Answer |
|----------|--------|
| 1. What is the vanishing gradient problem? | Gradients become exponentially small as they backpropagate through many layers, causing early layers to update extremely slowly or not at all. |
| 2. Which activation functions suffer from it? | **Sigmoid** and **Tanh** — their derivatives are ≤ 0.25 and approach 0 at the tails. |
| 3. Which activation functions do NOT suffer from it? | **ReLU** (derivative = 1 for z>0) and **GELU** (smooth, non-saturating). |
| 4. Why does it prevent learning? | Lower layers receive tiny gradients and don't update their weights. The network fails to learn useful features in early layers, effectively training only the output layers. |
| 5. Name two mitigation strategies. | **1. Use ReLU/GELU** activations (derivatives don't saturate). **2. Batch Normalization** — keeps activations in the active regime. **3. Residual Connections** — provide gradient "highways" (skip connections). |

</details>

<details>
<summary>📖 Click for Answers</summary>

| Observation | Diagnosis | Fix |
|-------------|-----------|-----|
| Many neurons output 0 in hidden layers | **Dying ReLU** | Use **Leaky ReLU**, **ELU**, or better **He initialization**. Lower learning rate. |
| Activations are near 0 or 1 in all layers | **Saturation** (Sigmoid/Tanh) | Switch to **ReLU** or **GELU**. Use **Xavier initialization**. |

| Training loss decreases, validation loss increases | **Overfitting** | Add **regularization** (L2, Dropout), get more data, early stopping. |
| Both train and validation loss are high and flat | **Underfitting** | Increase model capacity, add more layers/neurons, train longer, check for **data preprocessing issues**. |

## Exercise 13: "MLE vs Cross-Entropy Connection"

| Question | Your Answer |
|----------|-------------|
| 1. State the Maximum Likelihood Estimation (MLE) objective in mathematical form. | |
| 2. For classification, what distribution do we assume? | |
| 3. Show how Cross-Entropy loss is derived from MLE for binary classification. | |
| 4. Why do we use the **negative log-likelihood** instead of the likelihood directly? | |
| 5. In regression, what assumption leads to MSE? | |
| 6. How does the MLE framework unify different loss functions? | |

<details>
<summary>📖 Click for Answers</summary>

| Question | Answer |
|----------|--------|
| 1. MLE objective | `θ_hat = arg max θ P(D\|θ)` — find parameters that maximize the probability of the observed data. |
| 2. Distribution for classification | **Bernoulli** for binary, **Multinomial** for multiclass. |
| 3. Binary Cross-Entropy derivation | `P(y\|x) = y_hat^y · (1-y_hat)^(1-y)`. NLL: `-log P(y\|x) = -[y·log(y_hat) + (1-y)·log(1-y_hat)]` = **BCE**. |
| 4. Why negative log-likelihood? | The logarithm turns products into sums (easier to differentiate). Negation turns maximization into minimization (optimization algorithms minimize loss). |
| 5. What assumption leads to MSE? | **Gaussian (Normal) noise**: `y = wx + b + ε` where `ε ~ N(0, σ²)`. Maximizing likelihood is equivalent to minimizing squared residuals. |
| 6. How does MLE unify loss functions? | MLE provides a **probabilistic framework**: choose the distribution that matches your problem, and the loss function is derived automatically via negative log-likelihood. No need to invent ad-hoc loss functions. |

</details>

|-----------|--------------|----------------------------|

**Activation Functions Summary:**

| Activation | Output Range | Key Advantage | Key Disadvantage |
|------------|--------------|---------------|------------------|
| Sigmoid | (0, 1) | Natural for binary prob. | Vanishing gradients, not zero-centered |
| Tanh | (-1, 1) | Zero-centered | Vanishing gradients |
| ReLU | [0, ∞) | No vanishing gradient, sparse | Dying ReLU |
| Leaky ReLU | (-∞, ∞) | Prevents dying neurons | Not zero-centered |
| GELU | (-∞, ∞) | Smooth, state-of-the-art | Computationally expensive |
