## Exercise 7: "Weight Sharing & Parameter Efficiency"

**Scenario:** An image is 224×224×3 (RGB). You apply 64 filters of size 3×3 with stride 1 and padding 1.

| Question | Your Answer |
|----------|-------------|
| 1. How many parameters does this convolutional layer have (including biases)? | |
| 2. How many parameters would a Fully Connected layer have connecting the same input to the same output size? | |
| 3. What is the parameter reduction factor? | |
| 4. What is the "inductive bias" that weight sharing introduces? | |

<details>
<summary>📖 Click for Answers</summary>

| Question | Answer |
|----------|--------|
| 1. Convolution parameters | **(3×3×3 + 1) × 64 = (27 + 1) × 64 = 1,792** parameters |
| 2. FC parameters | Input size = 224×224×3 = **150,528**. Output size = 64 × 224 × 224 = **3,211,264** (same spatial size with 64 channels). FC parameters = 150,528 × 3,211,264 ≈ **4.8 × 10¹¹** (impossible to store). |

## Exercise 9: "Dilation (Atrous Convolution)"

| Question | Your Answer |
|----------|-------------|
| 1. What does dilation do? | |
| 2. For a 3×3 kernel with dilation rate = 2, what is the effective receptive field size? | |
| 3. Why use dilation instead of increasing kernel size? | |
| 4. When is dilation particularly useful? | |
| 5. What's the trade-off with dilation? | |

<details>
<summary>📖 Click for Answers</summary>

| Question | Answer |
|----------|--------|
| 1. What does dilation do? | Inserts "holes" (zeros) between kernel weights, expanding the receptive field without increasing parameters. |
| 2. Effective receptive field for dilation=2 | `K_eff = K + (K-1)(d-1) = 3 + (2)(1) = **5×5**` |
| 3. Why use dilation instead of larger kernel? | Dilation increases receptive field **without adding parameters** (3×3 dilated to 5×5 still has 9 parameters, vs 25 for a real 5×5 kernel). |
| 4. When is dilation particularly useful? | **Semantic Segmentation** — need global context while preserving spatial resolution (no downsampling). |
| 5. Trade-off with dilation | Can miss fine-grained details if dilation is too aggressive (large holes skip important local patterns). |

</details>

| 5. What does an IoU of 0 mean? | |
| 6. What does an IoU of 1 mean? | |

<details>
<summary>📖 Click for Answers</summary>

| Question | Answer |
|----------|--------|
| 1. Area of intersection | Intersection: x1=max(10,15)=15, y1=max(10,15)=15, x2=min(30,35)=30, y2=min(30,35)=30. Width=15, Height=15. **Area = 15 × 15 = 225** |

## Exercise 15: "ROI Pooling vs ROI Align"

| Question | Your Answer |
|----------|-------------|
| 1. What is the problem with ROI Pooling? | |
| 2. How does ROI Align solve it? | |
| 3. Which method is used in Mask R-CNN? | |
| 4. Why is ROI Align essential for instance segmentation? | |

<details>
<summary>📖 Click for Answers</summary>

| Question | Answer |
|----------|--------|
| 1. Problem with ROI Pooling | Performs **hard quantization** (rounding) of coordinates to map to fixed-size grids. This causes **misalignment** between the ROI and the feature map, hurting pixel-level precision. |
| 2. How ROI Align solves it | Uses **bilinear interpolation** instead of rounding. Samples four points per grid cell to preserve precise spatial information. |
| 3. Which method is used in Mask R-CNN? | **ROI Align** — crucial for accurate mask prediction. |
| 4. Why is ROI Align essential for segmentation? | Segmentation requires **pixel-perfect precision**. Any misalignment from rounding leads to blurry masks and poor boundary accuracy. |

</details>

**CNN Core Principles:**

| Principle | Description |
|-----------|-------------|
| **Local Receptive Fields** | Neurons connect to local patches of input, capturing spatial patterns |
| **Weight Sharing** | Same filter (kernel) applied across entire input → reduces parameters |
| **Translation Invariance** | Features detected regardless of location in the image |

**CNN Building Blocks Formula:**

| Operation | Output Size Formula |
|-----------|---------------------|
| Convolution (with padding P, stride S) | `O = (I - K + 2P)/S + 1` |
| Pooling | `O = (I - K)/S + 1` |
| Transposed Convolution | `O = (I - 1)S + K - 2P` |

**Pooling Methods:**

| Method | Operation | Purpose |
|--------|-----------|---------|
| **Max Pooling** | Selects maximum in window | Retains strongest feature response |
| **Average Pooling** | Computes average in window | Smoothes feature map |

**Upsampling Methods:**

| Method | Learnable? | Use Case |
|--------|------------|----------|
| **Nearest Neighbor** | ❌ No | Fast, simple upsampling |
| **Bilinear** | ❌ No | Smooth, artifact-free expansion |
| **Transposed Convolution** | ✅ Yes | Learned upsampling for dense tasks |

**Computer Vision Tasks:**

| Task | Output | Architecture Example |
|------|--------|---------------------|
| **Classification** | Single class label | ResNet, ViT |
| **Object Detection** | Bounding boxes + labels | Faster R-CNN, YOLO |
| **Semantic Segmentation** | Pixel-wise class labels | U-Net |
| **Instance Segmentation** | Mask per object | Mask R-CNN |
| **Keypoint Detection** | Sparse (x,y) coordinates | HRNet, OpenPose |

**Detection Metrics:**

| Metric | Definition | When to Prioritize |
|--------|------------|-------------------|
| **IoU** | Intersection / Union | Evaluating box localization accuracy |
| **Precision** | TP/(TP+FP) | When false positives are costly |
| **Recall** | TP/(TP+FN) | When false negatives are costly |
| **mAP** | Mean AP across classes | Standard detection benchmark |

**Pose Estimation Approaches:**

| Approach | How it Works | Example |
|----------|--------------|---------|
| **Bottom-Up** | Detect all parts first → associate | OpenPose |
| **Top-Down** | Detect person first → estimate keypoints | HRNet |

**Regularization in Vision:**

| Technique | Purpose in Vision |
|-----------|-------------------|
| **Data Augmentation** | Increases training variety; improves invariance |
| **Batch Normalization** | Stabilizes training; mild regularization |
| **Dropout** | Prevents co-adaptation of filters |
| **Weight Decay** | Penalizes large weights; smoother decision boundaries |
