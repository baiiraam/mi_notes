## 2. 🎯 TEACH IT SUMMARY

### The Big Picture — Week 6 ML

Week 6 covers **unsupervised learning** — finding structure in data without labels. The three main areas are dimensionality reduction, density estimation, and clustering.

**Part 1: Dimensionality Reduction.** The goal is to map high-dimensional data to a lower-dimensional space while preserving important structure. **PCA (Principal Component Analysis)** is a linear method that finds the directions of maximum variance — the principal components are the top eigenvectors of the covariance matrix. PCA has **two equivalent criteria**: minimize reconstruction error OR maximize projected variance — they're equivalent by the Pythagorean Theorem (`total variance = projected variance + reconstruction error`). PCA is fast, linear, and preserves global variance, making it great for preprocessing and visualization. **t-SNE** is a non-linear method specialized for **visualization**. It converts Euclidean distances to probabilities (Gaussian in high-D, Student-t in low-D) and minimizes KL divergence to preserve local topology. The **crowding problem** (more space in high dimensions) is solved by Student-t's heavier tails. **Perplexity** controls the effective number of neighbors (typical range 5-50). t-SNE is stochastic — different runs give different results — and is for visualization only, not for preprocessing other models.

**Part 2: Density Estimation.** **Kernel Density Estimation (KDE)** is a non-parametric density estimator that places a kernel function on every data point: `f̂(x) = (1/(nh)) Σᵢ K((x − xᵢ)/h)`. The **bandwidth h** controls smoothness — small h = under-smoothing (high variance), large h = over-smoothing (high bias). **Silverman's rule** (`h ≈ 1.06 × σ × n⁻¹/⁵`) is a good starting point but assumes normality. The **Improved Sheather Jones (ISJ)** algorithm is more robust for multimodal data.

**Part 3: Clustering.** Clustering assigns observations to homogeneous subgroups without labels. **K-means** minimizes within-cluster variation via iterative assignment and centroid updates. It requires K a-priori, converges to a local minimum (not global), and is random (different initializations → different results). **Hierarchical clustering** produces a dendrogram (tree structure) via agglomerative (bottom-up) merging. **Linkage methods** define inter-cluster distance: Complete (maximum), Average (mean), Single (minimum — causes chaining), Centroid (distance between centroids — causes inversions). **Correlation distance** clusters by patterns rather than magnitudes — useful for market segmentation where purchase patterns matter more than total volume.

**Part 4: Gaussian Mixture Models.** GMMs are a **probabilistic** (generative) view of clustering. The generative process: choose cluster z with probability πₖ, then sample x ∼ N(µₖ, Σₖ). The marginal is `p(x) = Σₖ πₖ N(x|µₖ, Σₖ)`. GMMs provide **soft assignments** (responsibilities `rₙₖ = p(zₙ=k|xₙ)`) via the EM algorithm. **EM** alternates: E-step computes responsibilities given current parameters; M-step updates parameters (πₖ, µₖ, Σₖ) given responsibilities. GMMs generalize K-means — K-means is the limiting case with hard assignments and spherical clusters. GMMs are universal density approximators and can model ellipsoidal clusters with different shapes.

**The Connecting Thread:** All three topics are unsupervised — finding structure without labels. PCA and t-SNE reduce dimensions for visualization/preprocessing; KDE estimates densities; clustering and GMMs find groups. GMMs are the probabilistic generalization of K-means, and EM is the optimization engine for latent variable models.

## 3. ⚠️ COMMON PITFALLS IN PRACTICE

| Pitfall | Why It Happens | How to Avoid |
|---------|----------------|--------------|
| **1. Using PCA to find clusters** | PCA finds variance, not clusters | Use t-SNE, K-means, or GMMs for clusters |
| **2. t-SNE without fixed random seed** | t-SNE is stochastic → non-reproducible | Set `random_state` for reproducibility |
| **3. Using t-SNE for preprocessing** | t-SNE doesn't preserve global distances | Use PCA for preprocessing; t-SNE for visualization only |
| **4. Not trying multiple perplexities** | Perplexity changes the visualization | Try perplexity 5, 30, 50 |
| **5. Over-interpreting t-SNE distances** | t-SNE preserves local structure, not global | Don't compare distances between clusters |
| **6. Using Silverman's rule for multimodal data** | Assumes normality → over-smooths | Use ISJ or cross-validation |
| **7. Using Euclidean distance for all clustering** | Patterns matter more than magnitudes | Use correlation distance for market segmentation |
| **8. Assuming K-means finds global optimum** | K-means converges to local minimum | Run multiple initializations |
| **9. Using too many clusters in K-means** | More clusters = lower inertia but less interpretable | Use elbow method or domain knowledge |
| **10. Assuming GMMs always outperform K-means** | GMMs are more flexible but need more data | Use K-means for simplicity; GMMs for ellipsoidal clusters |
| **11. Not checking cluster robustness** | Clusters may be artifacts | Run on random subsets; try different algorithms |
| **12. Not scaling variables before clustering** | Larger variance features dominate distance | Scale features before clustering |

### Clustering

<details>
<summary><b>Clustering</b> — Try your own first</summary>

**Model Answer:** An unsupervised learning method that assigns observations to homogeneous subgroups without class labels; algorithms include K-means, Hierarchical clustering, and GMMs.

</details>

---

<details>
<summary><b>K-Means Clustering</b> — Try your own first</summary>

**Model Answer:** Minimizes within-cluster variation (sum of squared distances to centroids) via iterative assignment and centroid updates; requires K a-priori and converges to a local minimum.

</details>

---

<details>
<summary><b>Hierarchical Clustering</b> — Try your own first</summary>

**Model Answer:** Produces a dendrogram (tree structure) of nested clusters; agglomerative (bottom-up) is most common — start with each point as its own cluster, iteratively fuse closest clusters.

</details>

---

<details>
<summary><b>Complete Linkage</b> — Try your own first</summary>

**Model Answer:** Distance between two clusters = **maximum distance** between any pair of samples, one in each cluster — produces compact, stable clusters.

</details>

---

<details>
<summary><b>Single Linkage</b> — Try your own first</summary>

**Model Answer:** Distance between two clusters = **minimum distance** between any pair of samples, one in each cluster — suffers from **chaining phenomenon** (long, stringy clusters).

</details>

---

<details>
<summary><b>Average Linkage</b> — Try your own first</summary>

**Model Answer:** Distance between two clusters = **average of all pairwise distances** between samples in the two clusters — a good general-purpose default.

</details>

---

<details>
<summary><b>Correlation Distance</b> — Try your own first</summary>

**Model Answer:** Clusters based on patterns/shapes rather than magnitudes — useful for market segmentation where purchase patterns matter more than total volume.

</details>

### Gaussian Mixture Models

<details>
<summary><b>GMM (Gaussian Mixture Model)</b> — Try your own first</summary>

**Model Answer:** A probabilistic (generative) clustering model where data is generated by choosing a cluster z with probability πₖ, then sampling x ∼ N(µₖ, Σₖ): `p(x) = Σₖ πₖ N(x|µₖ, Σₖ)`.

</details>

---

<details>
<summary><b>GMM Parameters</b> — Try your own first</summary>

**Model Answer:** πₖ (mixing coefficients — cluster probabilities), µₖ (means), Σₖ (covariances); often assume Σₖ = I for simplicity, but full covariance allows different spatial extents.

</details>

---

<details>
<summary><b>Responsibility (GMM)</b> — Try your own first</summary>

**Model Answer:** `rₙₖ = p(zₙ = k | xₙ)` — the probability that cluster k generated data point n; computed using Bayes rule, representing soft assignment in EM algorithm.

</details>

---

<details>
<summary><b>EM Algorithm for GMMs</b> — Try your own first</summary>

**Model Answer:** Expectation-Maximization alternates between E-step (compute responsibilities given current parameters) and M-step (re-estimate parameters given responsibilities) until convergence.

</details>

---

<details>
<summary><b>K-means vs GMMs</b> — Try your own first</summary>

**Model Answer:** K-means is hard assignment with spherical clusters; GMMs provide soft (probabilistic) assignments and can model clusters with different shapes and variances.

</details>

## 5. QUICK REFERENCE CHEAT SHEET — WEEK 6 ML

### PCA — Core Formulas

<details>
<summary><b>PCA Formulas</b> — Try to recall first</summary>

| Formula | Description |
|---------|-------------|
| `z = Uᵀ(x − µ)` | Code/representation (projection) |
| `x̂ = µ + Uz` | Reconstruction in original space |
| `Σ̂ = (1/n)Σ (xᵢ−µ)(xᵢ−µ)ᵀ` | Empirical covariance matrix |
| `‖x − µ‖² = ‖projection‖² + ‖residual‖²` | Pythagorean Theorem |
| Principal components | Top K eigenvectors of Σ̂ |

</details>

---

### PCA — Two Equivalent Criteria

<details>
<summary><b>Reconstruction Error vs Projected Variance</b> — Try to recall first</summary>

| Criterion | Goal |
|-----------|------|
| **Minimize reconstruction error** | `(1/n)Σᵢ ‖xᵢ − x̂ᵢ‖²` |
| **Maximize projected variance** | `(1/n)Σᵢ ‖zᵢ − mean(z)‖²` |

**They are equivalent!** Maximizing variance ≡ minimizing reconstruction error.

</details>

---

### t-SNE — Key Concepts

<details>
<summary><b>t-SNE Summary</b> — Try to recall first</summary>

| Aspect | Detail |
|--------|--------|
| **Purpose** | Visualization (2D/3D) |
| **Preserves** | Local structure / topology |
| **High-D similarity** | Gaussian: `pⱼ|ᵢ ∝ exp(−‖xᵢ−xⱼ‖² / 2σᵢ²)` |
| **Low-D similarity** | Student-t: `qⱼ|ᵢ ∝ (1 + ‖yᵢ−yⱼ‖²)⁻¹` |
| **Cost function** | `KL(P || Q) = Σ pⱼ|ᵢ log(pⱼ|ᵢ / qⱼ|ᵢ)` |
| **Perplexity** | Typical range 5–50 (commonly 30) |

</details>

<details>
<summary><b>KDE Formula</b> — Try to recall first</summary>

| Formula | Description |
|---------|-------------|
| `f̂(x) = (1/(nh)) Σᵢ K((x − xᵢ)/h)` | KDE (unweighted) |
| `h ≈ 1.06 × σ × n⁻¹/⁵` | Silverman's rule of thumb (Gaussian kernel) |

</details>

### KDE — Common Kernels

<details>
<summary><b>Kernel Functions</b> — Try to recall first</summary>

| Kernel | Formula |
|--------|---------|
| **Gaussian** | `K(x) ∝ exp(−x²/2)` (most common) |
| **Triangular** | `K(x) ∝ max(1−|x|, 0)` |
| **Box** | `K(x) ∝ 1` for `|x| ≤ 1`, 0 otherwise |
| **Triweight** | `K(x) ∝ (1−x²)³` for `|x| ≤ 1` |

</details>

### K-Means

<details>
<summary><b>K-Means Summary</b> — Try to recall first</summary>

| Aspect | Detail |
|--------|--------|
| **Objective** | Minimize `Σⱼ Σᵢ∈Cⱼ ‖xᵢ − µⱼ‖²` |
| **Algorithm** | (1) Random init, (2) Assign to nearest centroid, (3) Update centroids, repeat |
| **Convergence** | Always to a local minimum |
| **Randomness** | Different initializations → different minima |

</details>

| Method | Definition | Issue |
|--------|------------|-------|
| **Complete** | Maximum distance between pairs | - |
| **Average** | Average of all pairwise distances | - |
| **Single** | Minimum distance between pairs | Chaining phenomenon |

</details>

### GMM — EM Algorithm

<details>
<summary><b>GMM EM Steps</b> — Try to recall first</summary>

| Step | Action |
|------|--------|
| **E-step** | Compute responsibilities: `rₙₖ = p(zₙ=k|xₙ)` given current π, µ, Σ |
| **M-step** | Re-estimate: `πₖ = (1/n)Σrₙₖ`; `µₖ = (Σrₙₖxₙ)/(Σrₙₖ)`; `Σₖ = (Σrₙₖ(xₙ−µₖ)(xₙ−µₖ)ᵀ)/(Σrₙₖ)` |
| **Convergence** | Log likelihood does not decrease; non-convex (different initializations) |

</details>

---

### GMM — Marginal Distribution

<details>
<summary><b>GMM Formulas</b> — Try to recall first</summary>

| Formula | Description |
|---------|-------------|
| `p(x) = Σᵢ πᵢ N(x|µᵢ, Σᵢ)` | Marginal distribution (GMM) |
| `rₙₖ = p(zₙ=k|xₙ)` | Responsibility (soft assignment) |
| `log p(X) = Σₙ log [Σₖ πₖ N(xₙ|µₖ, Σₖ)]` | Log likelihood |

</details>

---

### K-means vs GMMs

<details>
<summary><b>K-means vs GMMs</b> — Try to recall first</summary>

| Aspect | K-means | GMMs |
|--------|---------|------|
| **Assignment** | Hard (one cluster) | Soft (probabilities/responsibilities) |
| **Covariance** | Spherical (implicit) | Can be full covariance |
| **Probabilities** | No | Yes |
| **Type** | Geometric | Probabilistic (generative) |

</details>

### 🔗 KEY CONNECTION EXPLANATIONS

<details>
<summary><b>Connection 1: How are PCA's two criteria equivalent?</b></summary>

```
PCA: Two Equivalent Criteria
    │
    ├── CRITERION 1: Minimize Reconstruction Error
    │       └── min (1/n) Σᵢ ‖xᵢ − x̂ᵢ‖²
    │
    ├── CRITERION 2: Maximize Projected Variance
    │       └── max (1/n) Σᵢ ‖zᵢ − mean(z)‖²
    │
    └── WHY THEY ARE EQUIVALENT
            │
            ├── Total Variance = Projected Variance + Reconstruction Error
            │       └── (Pythagorean Theorem)
            │
            ├── Total Variance is constant (depends only on data)
            │
            └── Therefore: minimizing reconstruction error
                    ⟺ maximizing projected variance

    Key Insight: Both criteria lead to the same subspace!
```

</details>

---

<details>
<summary><b>Connection 2: How does t-SNE improve on SNE?</b></summary>

```
SNE → Symmetric SNE → t-SNE
    │
    ├── SNE (Stochastic Neighbor Embedding)
    │       ├── Asymmetric conditional probabilities pⱼ|ᵢ
    │       └── Gaussian in both high-D and low-D
    │
    ├── Symmetric SNE
    │       ├── Symmetric similarities pᵢⱼ
    │       └── Still Gaussian in low-D
    │
    └── t-SNE (t-Distributed SNE)
            │
            ├── Student-t distribution in low-D
            │       └── Heavier tails → solves crowding problem
            │
            ├── Faster computation
            │       └── Simpler gradients
            │
            └── Better behavior
                    └── Better separation in visualization

    Key Insight: Student-t's heavier tails give more space in low-D.
```

</details>

<details>
<summary><b>Connection 3: How does bandwidth control the bias-variance tradeoff in KDE?</b></summary>

```
BANDWIDTH (h) IN KDE
    │
    ├── SMALL h (Under-smoothing)
    │       │
    │       ├── Many spikes (wiggly)
    │       ├── Low bias (captures details)
    │       ├── High variance (sensitive to data)
    │       └── Risk: overfitting
    │
    ├── LARGE h (Over-smoothing)
    │       │
    │       ├── Smooth curve
    │       ├── High bias (loses details)
    │       ├── Low variance (stable)
    │       └── Risk: underfitting
    │
    └── OPTIMAL h
            │
            ├── Balances bias and variance
            │
            ├── Silverman's Rule: h ≈ 1.06 × σ × n⁻¹/⁵
            │       └── Assumes normal distribution
            │
            └── ISJ algorithm: more robust for multimodal

    Key Insight: h = smoothing parameter — similar to regularization.
```

</details>

<details>
<summary><b>Connection 4: How do K-means and GMMs relate?</b></summary>

```
K-MEANS vs GMMs
    │
    ├── K-MEANS
    │       │
    │       ├── Hard assignment (each point belongs to one cluster)
    │       ├── Spherical clusters (implicit)
    │       ├── No probabilities
    │       └── Geometric (distance-based)
    │
    ├── GMMs
    │       │
    │       ├── Soft assignment (responsibilities)
    │       ├── Ellipsoidal clusters (full covariance)
    │       ├── Provides probabilities
    │       └── Probabilistic (generative)
    │
    └── GMMs generalize K-means
            │
            ├── If you force hard assignments in GMM:
            │       └── K-means = GMM with Σₖ = I and hard EM
            │
            ├── K-means = limiting case of GMM
            │
            └── GMMs are more flexible (different shapes, sizes)

    Key Insight: GMMs are a probabilistic version of K-means.
```

</details>

<details>
<summary><b>Connection 5: How does EM solve the GMM optimization problem?</b></summary>

```
GMM OPTIMIZATION
    │
    ├── Problem: Maximize log p(X) = Σₙ log [Σₖ πₖ N(xₙ|µₖ, Σₖ)]
    │       │
    │       ├── No closed-form solution
    │       └── Sum inside log → difficult
    │
    ├── If we knew cluster assignments zₙ
    │       │
    │       └── Complete data likelihood: easy to optimize!
    │
    ├── EM SOLUTION
    │       │
    │       ├── E-step: Compute responsibilities
    │       │       └── rₙₖ = p(zₙ=k | xₙ) using Bayes rule
    │       │
    │       ├── M-step: Update parameters
    │       │       ├── πₖ = (1/n) Σₙ rₙₖ
    │       │       ├── µₖ = (Σₙ rₙₖ xₙ) / (Σₙ rₙₖ)
    │       │       └── Σₖ = (Σₙ rₙₖ (xₙ−µₖ)(xₙ−µₖ)ᵀ) / (Σₙ rₙₖ)
    │       │
    │       └── Repeat until convergence
    │
    └── Key Insight: Replace unknown assignments with their expectations.
```

</details>

## 7. COMMON MISCONCEPTIONS — WEEK 6 ML

**How to use:** Read each misconception first. Try to identify what's wrong. Then click to reveal the reality.

---

### Misconception 1: "PCA finds clusters in the data."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| PCA can be used to find clusters in data. | **PCA does NOT find clusters:**
| | • PCA finds directions of **maximum variance** — not clusters |
| | • Clusters may or may not align with principal components |
| | • PCA is often used for **visualization** but it doesn't separate clusters |
| | • t-SNE is better for visualizing clusters |

**Rule:** PCA is for variance, not for clustering. Use t-SNE, K-means, or GMMs for cluster discovery.

</details>

---

### Misconception 2: "t-SNE always gives the same result for the same data."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| t-SNE is deterministic — same data = same plot. | **t-SNE is stochastic (random):**
| | • Different **initializations** → different results |
| | • Different **random seeds** → different results |
| | • Results can vary significantly between runs |
| | • Non-convex optimization (gradient descent with randomness) |

**Rule:** Use a fixed random seed for reproducibility. Always interpret t-SNE plots with caution.

</details>

---

### Misconception 3: "The crowding problem in t-SNE means the algorithm is broken."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| t-SNE's crowding problem is a flaw that makes it unreliable. | **The crowding problem is the REASON t-SNE works:**
| | • There is more space in high dimensions than low dimensions |
| | • Student-t distribution in low-D has heavier tails → gives more space |
| | • This is a feature, not a bug |

**Analogy:** Like trying to pack 100 people into an elevator — Student-t makes the elevator bigger (for far apart points).

</details>

---

### Misconception 4: "Perplexity in t-SNE is just another hyperparameter to guess."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| Perplexity is a magic number — just pick 30 and hope for the best. | **Perplexity has a meaningful interpretation:**
| | • Perplexity = smooth measure of **effective number of neighbors** |
| | • Low perplexity (5-10): focus on very local structure |
| | • High perplexity (30-50): more global structure |

**Rule:** Small dataset → lower perplexity; large dataset → higher perplexity. Always try multiple values.

</details>

---

### Misconception 5: "KDE and histograms are basically the same thing."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| KDE is just a smooth version of a histogram. | **KDE is fundamentally different:**
| | • **Histogram**: fixed bins → discontinuities, depends on bin boundaries |
| | • **KDE**: continuous, smooth, no bin boundaries |
| | • KDE places a kernel on **every data point** |

**Rule:** Use KDE for smooth density estimates; use histograms for quick visualization.

</details>

---

### Misconception 6: "The kernel in KDE must be a Gaussian."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| KDE uses Gaussian kernels — it's the only option. | **Many kernels can be used:**
| | • **Gaussian** (most common) — smooth, infinitely differentiable |
| | • **Triangular** — piecewise linear, finite support |
| | • **Box** — simplest, step-like |
| | • **Triweight** — smooth, finite support |
| | • Kernel choice matters less than bandwidth choice |

**Key Insight:** The **bandwidth h** is far more important than the kernel shape.

</details>

---

### Misconception 7: "Silverman's rule gives the optimal bandwidth for all data."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| Silverman's rule of thumb is the definitive bandwidth selection method. | **Silverman's rule makes a strong assumption:**
| | • Assumes data is **normally distributed** |
| | • Works well for unimodal data |
| | • **Fails for multimodal data** (over-smooths or under-smooths) |
| | • ISJ (Improved Sheather Jones) is more robust |

**Rule:** Use Silverman as a starting point. For multimodal data, use ISJ or cross-validation.

</details>

---

### Misconception 8: "K-means is deterministic — same data always gives the same clusters."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| K-means is deterministic. | **K-means is NOT deterministic:**
| | • Random **initialization** of centroids |
| | • Different initializations → different local minima |

**Rule:** Run K-means multiple times with different initializations. Select the run with the lowest within-cluster variation (inertia).

</details>

---

### Misconception 9: "More clusters in K-means always means better segmentation."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| More clusters = better model. | **Too many clusters = overfitting:**
| | • K-means objective always decreases with more clusters |
| | • At K=N, every point is its own cluster (inertia=0) |
| | • But this is useless for understanding data |

**Rule:** Choose K based on domain knowledge, elbow method, or gap statistic.

</details>

---

### Misconception 10: "Hierarchical clustering always produces the same tree regardless of linkage."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| Linkage method doesn't matter — the dendrogram is the same. | **Linkage method drastically affects the dendrogram:**
| | • **Complete**: compact clusters, stable |
| | • **Average**: balanced, good general-purpose |
| | • **Single**: chaining phenomenon (long, stringy clusters) |
| | • **Centroid**: inversions (dendrogram can go 'up' then 'down') |

**Rule:** Choose linkage based on desired cluster shape. Complete/Average are most commonly used.

</details>

---

### Misconception 11: "Clustering problems always have a 'correct' number of clusters."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| There is one true number of clusters in the data. | **The number of clusters is subjective:**
| | • Depends on the **granularity** of analysis needed |
| | • Different applications need different levels of detail |
| | • Formal methods (elbow, gap statistic) give suggestions, not answers |

**Rule:** The number of clusters is a **business decision**, not a statistical one.

</details>

---

### Misconception 12: "GMMs and K-means are completely different algorithms."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| GMMs and K-means are unrelated algorithms. | **GMMs generalize K-means:**
| | • K-means = GMM with **Σₖ = I** and **hard assignments** |
| | • K-means is the limiting case of GMMs |
| | • GMMs provide **soft assignments** (probabilities) |
| | • GMMs can model **different cluster shapes** |

**Analogy:** K-means is like a GMM wearing a straightjacket — it only allows spherical clusters.

</details>

---

### Misconception 13: "EM for GMMs always converges to the global optimum."

<details>
<summary><b>Click for Reality Check</b></summary>

| Misconception | Reality |
|---------------|---------|
| EM guarantees finding the best GMM parameters. | **EM converges to a LOCAL optimum:**
| | • The GMM log-likelihood is **non-convex** |
| | • Different initializations → different local optima |
| | • EM can get stuck in poor local minima |

**Rule:** Always run EM with multiple random initializations and select the best log-likelihood.

</details>

| 3. When to use | When we care about **purchase patterns** rather than total volume. When variables have different scales. |
| 4. Example | Market segmentation: Euclidean would cluster all customers who purchase few things together. Correlation would cluster customers who purchase **similar types** of things together. |

</details>

**PCA Projection:**

<details>
<summary>📖 Click for Answers</summary>

**PCA Projection:**
`z = **Uᵀ(x − µ)**`, `x̂ = **µ + Uz**`

**PCA Solution:** Principal components = top K **eigenvectors** of **the covariance matrix**

**t-SNE Purpose:** **Visualization** (2D/3D). Preserves **local** structure.

**t-SNE Cost Function:** `C = Σᵢ **KL(Pᵢ || Qᵢ)**`

**KDE Formula:** `f̂(x) = **(1/(nh)) Σᵢ K((x − xᵢ)/h)**`

**KDE Bandwidth:** Small h = **under-smoothing** (high variance); Large h = **over-smoothing** (high bias)

**K-Means Objective:** Minimize `Σⱼ Σᵢ∈Cⱼ **‖xᵢ − µⱼ‖²**`

**Hierarchical Clustering:** Produces a **dendrogram**; agglomerative = **bottom**-up.

**GMM Generative Process:** Choose cluster z with probability **πₖ**, then sample x ∼ **N(µₖ, Σₖ)**

**GMM Marginal:** `p(x) = **Σᵢ πᵢ N(x|µᵢ, Σᵢ)**`

**EM Algorithm:** E-step computes **responsibilities**; M-step updates **parameters (π, µ, Σ)**
